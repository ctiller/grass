# Source-resolved x86 branch correspondence

`Grass.Assembly.SourceBranchExecution.sourceBranch_checked_cases` classifies every admitted checked CPU outcome at a resolved JMP/JE/JA source output. Its inputs are the checked source/image binding, actual loaded image, current code allocation and cells, source position, and absence of import patches over this instruction. It does not assume successful fetch or accept an author-supplied decoder/classifier result.

Production branch encoding and canonical dispatcher completeness determine the actual instruction. A completed outcome retains the actual fetch and branch receipt, displacement, unchanged general registers, and target or fallthrough selected by incoming architectural flags. Supplied normal-choice flags cannot choose the branch direction. Failure and uncovered outcomes retain their exact reached state and applicability reason.

`Grass.Platform.Win32.Raw.RawStep.cpu_branch_successor` consumes an existing raw CPU edge. It preserves that edge's choice, event/graph agreement, fixed policy, checked outcome, and exact installed raw state. This platform adapter is not a cross-target execution contract.

Neither theorem establishes enabledness, physical event delivery, coverage of a processor, whole-path reachability, invariant preservation, API return, termination, or specification refinement. In particular an outside-profile outcome is not a physical no-op or termination. CALL continuation and provider return require their own actual transfer evidence.

The fixture is an independent source-derived branch program with arbitrary labels, passed through generic source extraction, frame derivation, linking and loading. An unreachable import-bearing block satisfies the current PE builder's nonempty import requirement; the fixture makes no claim to execute that API. The first tested state is placed at the selected source occurrence, without a whole-run reachability claim.

The next shared consumer obligation is deriving and preserving current code provenance/cells and patch exclusion through actual memory histories, then relating actual paths to original source decisions and annotations. These must not become per-program branch recipes or new author proof arguments. Other targets retain their own source/artifact/transition receipts: AArch64 branch/SVC body evidence, Wasm module/function/instruction provenance, and operand-local shader evidence do not imply complete platform or device execution.

Validation: the focused fixture build passed 220 jobs. It executes each source-derived JMP/JE/JA output with both incoming ZF values and deliberately opposite supplied flags, checks a genuine fetch-access refusal from conflicting registered context kind, and applies the raw consumer to an actual edge. Fault/trap/interruption/abort choices retain their exact outside-profile diagnostics. The platform ledger build passed 259 jobs with its existing 758 declarations (6 cited, 349 owed, 403 reviewed as nonbehavior). A dependency audit including the fixture scanned 20,564 Grass declarations across 219 Grass/test modules: no unapproved axiom, unsafe declaration, or compiled override; both public theorem roots use only `propext`, `Classical.choice`, and `Quot.sound`. Independent Terra review approved the final change. Broad repository integration audits remain execution's responsibility.

Integration prerequisites: generic source extraction from frontend `ea0368bc` plus its kernel-reduction correction `a9e07850`, and x86 dispatcher branch completeness `f0cbb1a0` (equivalent checkpoint `cb4a720e`). The lowering commit contains its own delta rather than reimplementing those owners' APIs.

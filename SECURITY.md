# Security policy

Grass has no released implementation or executable artifact yet. Security
reports can nevertheless concern the specification, trust boundary, validation
tools, repository automation, or accidental disclosure of sensitive data.

Do not report a suspected vulnerability in a public issue, discussion, commit,
or agent-bus event. Use the repository host's private vulnerability-reporting
facility when one is advertised for this repository. Include the affected
revision, impact, reproduction or proof sketch, and any suggested remediation.

Before the repository is made public, its maintainers must enable and test a
private reporting route. If no private route is visible, do not transmit
sensitive details publicly; ask the maintainers to establish one first.

There are currently no supported releases. The `main` branch is a changing
design corpus and receives correctness and disclosure fixes, but it carries no
compatibility or deployment guarantee.
